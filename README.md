# Web Helper

Tampermonkey-скрипт, который убирает рутину при разборе платёжных тикетов в TH Management. Подготовлен для конкурса **Bet on Better**.

Один файл и одна установка. Восемь помощников включаются и выключаются тумблерами прямо на странице. Скрипт ничего не подтверждает и не отправляет за оператора. Он показывает информацию, заполняет пустые поля и закрывает только штатные окна «OK!».

## Установка

1. Поставить в браузер расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Открыть ссылку и нажать **Install**:
   **[web-helper.user.js](https://raw.githubusercontent.com/partenkoEgor/Web_Helper/main/web-helper.user.js)**
3. Обновить страницу админки.

Дальше скрипт обновляется сам: Tampermonkey периодически сверяет `@version` и подтягивает новую версию из `main`.

### Превью вложений

Наводишь курсор на ссылку на файл, и рядом всплывает превью:

- **картинки** (`png`, `jpg`, `gif`, `webp`, `bmp`) показываются целиком;
- **PDF** и **видео** показываются иконкой и именем файла, открываются кнопкой **Open in new tab**.

Кнопка **Fullscreen** открывает полноэкранный просмотр. В нём можно листать все картинки ячейки (`←` / `→`), поворачивать на 90°, увеличивать колесом мыши в точку под курсором и двигать картинку мышью. Двойной клик сбрасывает поворот и масштаб, `Esc` закрывает просмотр.

Картинка остаётся чёткой при увеличении: скрипт меняет размер в вёрстке, а не растягивает готовый растр через `transform: scale`.

### Предыдущий статус и кто в работе

Наводишь курсор на ячейку **External Status**:

- у `Closed` / `Closed (M)` подсказка показывает статус, который был до закрытия;
- у `In progress` / `In progress (M)` она показывает, **у кого тикет в работе** (Admin username из самой свежей записи истории).

История запрашивается тем же запросом, что окно «История тикета», и запоминается на минуту.

### Автоподстановка Reddy ID

В окне **Export to Reddy** поле Reddy ID заполняется вашим ID автоматически. ID скрипт сам находит в разметке страницы и запоминает. Поле заполняется, только если оно пустое, а отправляете вы сами. Задать или сбросить ID вручную можно через меню Tampermonkey → **Web Helper: мой Reddy ID**.

### Автоподстановка дат

Когда выбираете фильтр в окне **Saved filters** и жмёте в нём **Apply**, диапазон дат заполняется сегодняшним днём, например `11.10.2026 00:00 ~ 11.10.2026 23:59`. Apply в основной панели фильтров и в других окнах даты не трогает.

Длинные ссылки вида `WebUserDocuments/889142155/Consultant/a32456d4….jpg` в колонках **User files**, **Agent's files**, **Support team's files** и **Internal files** превращаются в компактные кнопки `1. Скрин`, `2. PDF`, `3. Видео`. Цвет кнопки зависит от типа файла: картинки бирюзовые, PDF оранжевые, видео фиолетовые, всё остальное красное. Превью при наведении работает и на кнопках.

### Обмен сохранёнными фильтрами

Рядом с кнопкой **Saved filters** появляется кнопка «поделиться». Отмечаете свои фильтры и копируете код вида `TH-FILTERS:z:H4sIAAAA…`. Коллега вставляет этот код у себя, и фильтры вместе с набором колонок добавляются в его «Saved filters». Существующие фильтры не затираются: если имя занято, к нему добавляется номер.

Фильтры читаются и сохраняются теми же запросами, что использует сам сайт (`/admin/filter/get`, `/admin/filter/save`). Если в коде несколько фильтров, они сохраняются по одному с паузой 0,5 секунды, чтобы не слать сайту десятки запросов подряд. На кнопке видно, сколько уже добавлено: «Добавляю 3 из 30…».

### Автозакрытие попапов «OK»

Работает во **всём бэкофисе**. Окно SweetAlert2 закрывается, только если выполнено всё сразу:

- иконка успеха;
- текст «OK!» (кириллические «ОК» тоже распознаются);
- кнопка «OK»;
- нет кнопки отмены.

Окна с ошибками и вопросами скрипт не трогает. Каждое закрытие пишется в консоль (`F12` → Console) с заголовком окна:

```
[AutoClose] Закрыл попап: title "...", содержимое "OK!", кнопка "OK"
```

## Панель настроек

Круглая кнопка **⚙** в левом нижнем углу страницы тикетов открывает панель с тумблером для каждой функции. Та же панель доступна на любой странице через меню Tampermonkey → **Web Helper: Настройки**. Выбор сохраняется в Tampermonkey, переживает обновления скрипта и действует сразу на всех трёх доменах. Изменения вступают в силу после обновления страницы, и панель предлагает сделать это одной кнопкой.

Значения по умолчанию и параметры каждой функции лежат в блоке `CONFIG` в начале скрипта.

## Разрешения

| Разрешение | Зачем |
|---|---|
| `GM_getValue`, `GM_setValue` | Хранить настройки панели и Reddy ID |
| `GM_registerMenuCommand` | Пункты «Настройки» и «мой Reddy ID» в меню Tampermonkey |
| `unsafeWindow` | Узнать тему админки (светлая или тёмная), чтобы окна скрипта выглядели как сайт |

Запросов на сторонние домены скрипт не делает: всё идёт на сам сайт админки.
