# Скриншоты для README

Картинки из этой папки показываются в свёрнутых блоках «📸 Скриншот» в [README](../../README.md). Имя файла должно совпадать с указанным в таблице, иначе картинка не появится.

| Файл | Что на скриншоте |
|---|---|
| `file-preview-popup.png` | Превью картинки при наведении на ссылку |
| `file-preview-pdf.png` | Превью первой страницы PDF |
| `file-preview-fullscreen.png` | Полноэкранный просмотр (панель поворота и масштаба видна) |
| `prev-status.png` | Подсказка на статусе `Closed`: статус до закрытия |
| `in-work.png` | Подсказка на статусе `In progress`: у кого тикет в работе |
| `reddy-id.png` | Окно Export to Reddy с уже заполненным Reddy ID |
| `date-range.png` | Поле диапазона дат после Apply |
| `file-buttons.png` | Цветные кнопки `1. Скрин`, `2. PDF` в колонках файлов |
| `cell-copy.png` | Ячейка, подсвеченная зелёным после копирования |
| `filter-share.png` | Окно «Обмен фильтрами», вкладка «Поделиться» |
| `filter-import.png` | Окно «Обмен фильтрами», вкладка «Добавить по коду» |
| `auto-close-console.png` | Консоль браузера со строкой `[AutoClose] Закрыл попап…` |
| `settings-panel.png` | Панель настроек ⚙ с тумблерами |

## Перед загрузкой

Репозиторий публичный: скриншоты увидит любой. Замажьте всё, что относится к реальным людям и платежам: User ID, Ticket ID, кошельки, суммы, номера транзакций, имена и логины админов, Reddy ID, внутренние адреса.

Удобная ширина скриншота — 1200–1600 px. В README картинка ужимается до 760 px, а по клику открывается в полном размере.

## Как загрузить

На GitHub: открыть эту папку → **Add file** → **Upload files** → перетащить файлы → **Commit changes**.
